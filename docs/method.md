# Experiment methodology: field-note summary

**September 2026.** This is a historical summary, not a fully reproducible benchmark: original private run manifests and public-safe raw outputs are not attached.

**Question:** Can an externally defined identity and explicitly supplied conversation context retain recognizable continuity when the inference model changes?

External state: `persona.md`, `voice.md`, `boundaries.md`, and `memory.md`, plus visible conversation turns. Hidden model state is not transferred.

Stages: (1) model screening; (2) reconstruction and forks across DeepSeek, Kimi, and GLM; (3) a focused blind human preference comparison between DeepSeek and Kimi.

Evaluated dimensions included character fidelity, visible continuity, memory provenance, inference restraint, technical reasoning, register-switching, tool-output governance, and reliability.

**Stage 3 observation:** one evaluator, eight planned episodes, seven scoreable; DeepSeek preferred in 5, Kimi in 1, tie in 1.

Limitations: highly character-specific prompts and one evaluator; small nonrepresentative episode set; model route, inference parameters and provider may confound results; no general model rankings or significance claim. The complete private test material is not published. The generic public character is different from the tested private character and the separate Brixana demonstration.

For full reproducibility, the project would need precise configs, original run hashes/checkpoints, timestamps, and real public-approved prompt/output pairs. None are claimed here.
